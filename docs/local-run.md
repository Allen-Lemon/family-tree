## 启停

在项目根目录的 PowerShell 中执行：

```powershell
.\scripts\start-local.ps1
.\scripts\stop-local.ps1
```

可追加 `-Service Backend` 或 `-Service Frontend` 单独启动/停止。启动脚本会检查端口是否被占用；不要重复启动。停止脚本仅停止 PID 文件记录且命令行仍属于本项目的进程，不会删除远程数据库。

脚本优先使用 `JAVA_HOME`，否则使用本机已有 `C:\Users\Administrator\family-tree-env\jdk-21.0.1`。Node 从 PATH 获取。

日志、PID 和浏览器截图位于 `logs/`。上传及应用生成的备份位于 `data/uploads/` 下，均需保留。不要清理数据目录来重启服务。

## 普通管理员与个人信息字段模版（2026-11-11）
