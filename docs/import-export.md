# 导入与导出说明

## 支持格式

建议最低支持：

- GEDCOM 5.5.1 UTF-8：家谱交换；
- CSV UTF-8（带表头）：成员批量导入/导出；
- JSON：系统完整结构化导出，使用带版本的 schema；
- ZIP：JSON/GEDCOM 与媒体文件的归档包。

实现可增加 XLSX，但应明确模板版本。不得把“任意 Excel”当作稳定契约。

## 导入流程

1. 上传后生成任务，原文件进入隔离区；
2. 校验大小、文件头、编码和可选病毒扫描；
3. 解析为暂存数据，不直接写正式表；
4. 验证必填字段、日期、性别枚举、重复人物、循环关系和文件引用；
5. 展示预检摘要及逐行错误；
6. 用户确认后，以事务或可恢复批次提交；
7. 记录操作者、文件哈希、格式、数量、错误和结果；
8. 提供幂等键，避免重复提交。

导入失败不得产生半成品关系。大文件异步处理，接口返回任务 ID，通过任务状态查询进度。

## CSV 模板

建议字段：

```text
externalId,name,formerName,gender,birthDate,deathDate,fatherExternalId,motherExternalId,spouseExternalIds,phone,email,biography
```

- 日期用 `YYYY-MM-DD`，未知可空；
- 多值按模板约定的安全分隔规则，不自行猜测；
- `externalId` 在单次导入内唯一，用于关联；
- 导入时去除 CSV 公式前缀风险；导出到表格时以安全方式处理以 `= + - @` 开头的单元格。

## GEDCOM

保留无法映射的标签或在报告中明确列出丢弃项。支持 `INDI`、`FAM`、姓名、性别、生卒事件及父母/配偶/子女引用。拒绝悬空引用和不合理循环，并对层级、记录数和行长度设置上限。

## 导出流程

- 用户选择家谱、格式、字段范围及是否包含媒体；
- 后端重新校验对象级权限；敏感字段默认不导出；
- 大型导出异步生成一次性下载链接，短时有效、绑定用户；
- ZIP 路径标准化，禁止 `../`；附带 `manifest.json`，包含 schema 版本、时间、数量和文件哈希；
- 下载、失败、取消和过期均写审计日志；到期自动清理临时文件。

## JSON 版本化

顶层建议包含：

```json
{
  "schemaVersion": "1.0",
  "exportedAt": "2026-01-01T00:00:00Z",
  "family": {},
  "persons": [],
  "relationships": [],
  "media": []
}
```

新增可选字段可保持向后兼容；删除、改名或语义变化必须提升主版本并提供迁移说明。

## 验收要点

- 导入前预检和错误定位清晰；
- 重复提交不重复创建记录；
- 非授权用户无法导入或导出其他家谱；
- 导出后重新导入，核心成员与关系数量一致；
- 恶意文件名、压缩炸弹、公式注入、超限文件和损坏编码被拒绝；
- 日志不包含导入全文或敏感数据。
