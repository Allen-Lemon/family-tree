# 安全说明

## 秘密与身份

- `.env` 仅放在部署主机，最小权限读取，禁止提交 Git、聊天传输或写入镜像；
- `MYSQL_PASSWORD`、`MYSQL_ROOT_PASSWORD`、`ADMIN_PASSWORD`、`APP_DATA_ENCRYPTION_KEY` 使用不同的随机值；
- 生产优先使用编排平台 secret 或外部秘密管理服务，并制定轮换流程；
- 初始管理员仅在空库创建，首次登录强制改密；管理员启用 MFA（若实现）；
- 密码使用强哈希（Argon2id 或 bcrypt），不明文存储；登录接口限速并记录审计；
- 令牌短时有效，刷新令牌可撤销；Cookie 模式必须使用 HttpOnly、Secure、SameSite。

## 网络与传输

- 生产强制 HTTPS，TLS 1.2+；MySQL 不暴露宿主机端口；
- 后端端口只绑定 loopback，公网仅开放反向代理；
- CORS 精确列出可信 HTTPS 来源，禁止凭据模式配合通配符；
- 配置信任代理边界，防止伪造 `X-Forwarded-For`；
- 对登录、上传、OCR、导入和导出实施速率/并发限制。

## 授权与数据隔离

所有接口在服务端执行身份认证和对象级授权，不依赖前端隐藏按钮。建议 RBAC：管理员、编辑者、只读访客；家谱、成员、媒体、导出任务均校验所属范围。批量导出、用户管理、删除及恢复属于高风险操作，应二次确认并审计。

## 上传、导入和 OCR

- 限制文件大小、数量、扩展名，并通过文件头验证 MIME；
- 上传文件使用服务端生成的名称，存放于 Web 根目录外；拒绝路径穿越、压缩炸弹和宏；
- 可启用 ClamAV，扫描失败默认阻断而非放行；
- CSV 防止公式注入，Excel/XML 解析禁用外部实体；
- OCR 默认关闭外发；开启前执行隐私影响评估、最小化数据并明确保留期；
- 外部 Provider 密钥不返回前端，不记录在日志。

## 应用安全

- 所有数据库操作参数化，输出按上下文编码，富文本采用允许列表净化；
- JSON 错误响应不暴露堆栈、SQL 或内部路径；
- 删除操作宜软删除并支持授权恢复；并发更新使用版本号/ETag；
- 依赖和基础镜像定期扫描，锁定生产版本并及时修补高危漏洞；
- 为镜像生成 SBOM，验证来源；容器以非 root 运行（Nginx 镜像入口除外时应进一步加固）。

## 日志、备份与事件响应

日志和审计数据避免敏感内容；审计日志防篡改并设置保留期。备份加密、离机保存、定期恢复演练，恢复权限独立管理。发生泄露时立即隔离、保全证据、吊销令牌和轮换密钥，评估影响范围，并按适用法律与组织流程通知。

## 上线检查

- `.env` 无占位符且权限正确；
- 外网无法访问 MySQL 和后端调试端口；
- HTTPS、CORS、上传限制、限流、权限矩阵已验证；
- OCR 仍禁用，或已有正式审批和数据处理协议；
- 漏洞扫描无未接受的高危项；
- 备份恢复与安全事件联系人有效。
